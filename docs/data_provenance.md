# Data provenance

The uploaded shipment sensor datasets are simulated prototype data generated for a Berlin to Rotterdam shipment route. They are useful for building and demonstrating the dashboard architecture, but they should not be described as real-world observations in the final submission.

For the final assessed version, add a credible public logistics or IoT dataset and clearly document:

- Source URL
- Creator or publisher
- Date range
- Variables used
- License or reuse permissions
- Cleaning decisions

Recommended source to integrate: UCI Daily Demand Forecasting Orders. UCI describes it as 60 days of real data from a large Brazilian logistics company.
